# Rate limit

This crate provides a fixed-capacity GCRA engine for node-local policy
admission. HTTP requests are admitted atomically against a source bucket and
an optional rule-global bucket; a denial returns status 429 without consuming
the other bucket. L4 accounting applies only to new connections and new UDP
flows. Existing sessions bypass admission.

Counter identity includes generation, policy, rule, source, and bucket scope.
Disable and generation cleanup discard counters deterministically. Capacity
exhaustion and monotonic-time regression fail closed. The engine does not read
wall-clock time, allocate state dynamically, or claim cluster-global quotas.

The pinned public `nre:policy/v1` SDK does not yet expose a monotonic clock or
generation-local atomic state mutation. Pure Rust engine tests remain usable,
but `nre_policy_init` and the package capability gate fail closed with
`INCOMPATIBLE_ABI`. No private Host call or ABI extension is introduced.

`artifacts/rate-limit.wasm`, package digests, and signatures are generated by
the repository build pipeline and are not source assets.
