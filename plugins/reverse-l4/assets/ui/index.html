四层反向穿透

反向穿透映射

公网客户端连接入口节点上的端口。出口节点主动建立反向通道（可选中继），再访问它能到达的内网服务。回程沿同一条链路返回。

流量关系说明

1 公网客户端连接入口连的是入口节点上的监听端口，不是出口，也不是面板
→
2 反向通道送到出口出口主动建链。无中继则直连入口；有中继则按添加顺序从入口走到出口
→
3 出口连接内网服务由出口节点访问这个地址；不是入口去连

转发顺序：客户端 → 入口 → 第 1 跳中继 → 第 2 跳中继 → … → 出口 → 内网服务。不添加中继时，入口与出口直连。

地址归属：127.0.0.1 表示出口节点自身，不是入口节点，也不是管理面板所在机器。
