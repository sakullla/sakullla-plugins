入口模式

入口身份由 Host 核验。WAF 和其它 deny 阶段不会被 IP 允许覆盖。

TCP、UDP 与受管入口通过同一 Host-owned entry identity 设置模式；HTTP 额外支持隔离的 stage overlay 规则。

规则
