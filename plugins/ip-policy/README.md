# IP policy

The crate implements bounded IPv4/IPv6 prefix tries for shared policies and
per-binding overlays. Deny branches are evaluated across both tries before any
allow branch. Connection source provenance and GeoIP lookups are Host-owned;
raw X-Forwarded-For input and `.mmdb` files are never accepted as policy data.

The pinned public `nre:policy/v1` SDK does not yet authenticate whether a
source field came from socket, PROXY protocol, or Relay metadata. The pure
engine and corpus tests remain usable, but `nre_policy_init` and the package
capability gate fail closed with `INCOMPATIBLE_ABI`. No private Host field or ABI
extension is introduced here.

`artifacts/ip-policy.wasm`, package digests, and signatures are generated by the
repository build pipeline and are not source assets.
