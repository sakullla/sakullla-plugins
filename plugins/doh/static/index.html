DNS over HTTPS

把当前入口配进浏览器或系统

这是 DNS over HTTPS（DoH），不是 DNS over TLS。把下面由当前页面地址生成的解析入口填进支持安全 DNS 或加密 DNS 的设置即可。入口带路径时，解析地址会跟当前路径走，不必猜测插件内部地址。

解析地址

当前入口的 RFC 8484 端点

地址等于当前页面所在路径加上 /dns-query。入口在子路径时会带上该路径。复制后可直接粘贴到下方步骤里的自定义提供商。

/dns-query

配置步骤

能粘贴这串地址的地方

上方是完整 DoH URL（含 https:// 和 /dns-query），不要只填主机名。Chrome / Edge 只改浏览器自己的查询；Windows 11 覆盖本机大部分应用。系统开了加密 DNS 后，不必再在浏览器里配一遍。Firefox 占用低，本页不写。

  1. 1

    Chrome / Edge

    Chrome：右上角 ⋮ → 设置 → 隐私和安全 → 安全 → 打开「使用安全 DNS」→ 自定义提供商，粘贴上方整段地址。Edge 在「隐私、搜索和服务」里滚到「安全」，其余相同。只保护这个浏览器，不管系统或其他 App。

  2. 2

    Windows 11

    设置 → 网络和 Internet → 以太网或 WLAN → 点当前网络。DNS 服务器分配 → 编辑 → IPv4 选手动。打开加密 DNS / DNS over HTTPS，模板选手动，把上方整段 URL 填进模板后保存。
