配置步骤：Chrome / Edge 与 Windows 11

把上面的整段地址粘贴到对应设置。系统级加密 DNS 生效后，浏览器里不必重复配置；只配浏览器则只影响该浏览器。

  1. 1

    Chrome / Edge

    Chrome：⋮ → 设置 → 隐私和安全 → 安全 → 使用安全 DNS → 自定义，粘贴整段地址。Edge：「隐私、搜索和服务」→ 安全 → 使用安全 DNS → 自定义，其余相同。

  2. 2

    Windows 11

    设置 → 网络和 Internet → 当前网络（以太网或 WLAN）→ DNS 服务器分配 → 编辑 → IPv4 手动，打开加密 DNS，模板选「手动」并粘贴整段地址后保存。
