DNS over HTTPS

把当前入口配进浏览器或系统

这是 DNS over HTTPS（DoH），不是 DNS over TLS。把下面由当前页面地址生成的解析入口填进支持安全 DNS 或加密 DNS 的设置即可。入口带路径时，解析地址会跟当前路径走，不必猜测插件内部地址。

解析地址

当前入口的 RFC 8484 端点

地址等于当前页面所在路径加上 /dns-query。入口在子路径时会带上该路径。复制后可直接粘贴到下方步骤里的自定义提供商。

配置步骤

Chrome / Edge、Firefox 与 Windows 11

  1. Chrome / Edge

    打开设置 → 隐私和安全（Edge 为「隐私、搜索和服务」）→ 安全 → 使用安全 DNS。选择自定义提供商，粘贴上方地址。

  2. Firefox

    打开设置 → 隐私与安全 → DNS over HTTPS。启用后选择自定义提供商，填入上方地址。

  3. Windows 11

    打开设置 → 网络和 Internet → 以太网或 WLAN → DNS 服务器分配 → 编辑。打开加密 DNS / DNS over HTTPS（手动模板），把上方地址填进模板。
