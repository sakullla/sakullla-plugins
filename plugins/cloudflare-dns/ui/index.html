Token 怎么获取？最长匹配如何生效？
1 打开 API TokensCloudflare 控制台 → 右上角头像 → My Profile → API Tokens → Create Token
2 用自定义 Token选 Custom token。权限至少 Zone → DNS → Edit；建议再加 Zone → Zone → Read。区域资源选 Include → Specific zone，只包含本映射要用的域名
3 创建后立刻复制Continue to summary → Create Token。密钥只显示一次，粘贴到本页后不会再回显

最长匹配：同时有 example.com 和 shop.example.com 时，www.shop.example.com 用更长的 shop.example.com。官方步骤与截图
